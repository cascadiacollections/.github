# Security policy

This is the default policy for every `cascadiacollections` repository that doesn't have its own
`SECURITY.md`.

## Reporting a vulnerability

Report it privately through the affected repository's **Security** tab:
**Report a vulnerability** (`https://github.com/cascadiacollections/<repo>/security/advisories/new`).

Please don't open a public issue, pull request, or discussion for a security problem.

Include what's affected (repository, version or commit), how to reproduce it, and the impact you
expect. You'll get an acknowledgement within a week. A fix or a plan follows once the report is
confirmed, and you're credited in the advisory unless you'd rather not be.

## Supported versions

Only the latest release, or the default branch for projects without releases, gets security fixes.
