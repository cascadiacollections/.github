# Contributing

Thanks for helping out. This is the default guide for every `cascadiacollections` repository that
doesn't have its own `CONTRIBUTING.md`. Read the repository's README for how to build and test it.

## Developer Certificate of Origin (DCO)

Sign off your commits:

```sh
git commit -s
```

This adds a `Signed-off-by:` trailer certifying the [Developer Certificate of
Origin](https://developercertificate.org): you wrote the change, or otherwise have the right to
submit it under the repository's license. That keeps the copyright provenance clean without a
CLA.

## Licensing of contributions

By contributing, you agree your changes are licensed under the license of the repository (or of
the directory, where a repository licenses parts differently; its README says so).

Contributions don't grant rights to project names, logos, or icons. Where a repository has a
`TRADEMARK.md`, it explains what's reserved.

## Pull requests

- Keep each PR focused, and separate refactors from behavior changes.
- Run the repository's tests and linters before pushing.
- For anything large, open an issue first to agree on the approach.

## Security

Report vulnerabilities privately, as [SECURITY.md](SECURITY.md) describes, not in an issue or PR.
