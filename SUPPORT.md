# Support

This is the default for every `cascadiacollections` repository that doesn't have its own
`SUPPORT.md`.

## Questions

Search first. Then ask in one of these places:

- The repository's **Discussions** tab, when that repository has Discussions turned on.
- The organization discussions: <https://github.com/orgs/cascadiacollections/discussions>

Use an issue only when the repository has no Discussions and the question is about a bug or a
change. Say that it's a question.

Security reports don't belong in discussions or issues. Follow [SECURITY.md](SECURITY.md).

## What to expect

Replies are best effort. There's no support contract and no promised response time.
